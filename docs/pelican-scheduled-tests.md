# 鹈鹕测智（custom）

迁移自 [ranxi2001/sub2api](https://github.com/ranxi2001/sub2api) 的 `production` 分支，参考提交 `1ff6397fae6d1bd9e7f420a5a6620b4f786efb13`。绘图用于人工比较模型输出，也可主动提交 HTML 进行第三方质量分类；原答案质量判定继续保留。

## 满血 AI 作品评估

分组测试的作品预览、账号手动/定时测试结果、账号历史记录详情增加“评估作品”。打开预览只查询本站已保存结果；管理员点击后才向 [满血 AI](https://manxue.ai/api) 上传该作品的 HTML。目前没有自动上传开关，不调用该站的模型生成接口。

- 固定请求地址为 `https://manxue.ai/api/v1/tests`，请求体严格只有 `benchmark: "pelican"` 和 `html`。HTML 源码不超过 2 MiB；不发送 API Key、上游地址、模型参数、账号资料、票据或 OAuth 凭据。
- 本站接口只接受 `html` 字段，拒绝 `api_key`、`base_url`、`credentials` 等额外字段。评估服务没有账号或凭据依赖；使用独立 HTTP 客户端，无 Cookie、代理鉴权和凭据插件，不复制入站请求头、不跟随重定向。
- 优先提取原始生成源码，不上传本站预览加入的 CSP 或测量脚本。只含 SVG 时沿用已有的独立 HTML 包装；非 HTML/纯文本答案不显示评估入口。
- 异步查询结果，尊重服务繁忙时的 `Retry-After`。关闭预览停止本站轮询；重新打开可接续已有任务。成功分类、原因、来源及评估时间按源码 SHA-256 保存到新增 `pelican_html_assessments` 表；该表不保存源码或凭据。同一份作品在不同入口复用结果，不重复上传。
- 分类为“正常”“疑似降智”“无法判定”。网络错误、无效结果和任务超时不算降智，也不会修改账号状态、分组调度或作品生成状态。按对方文档，该结果来自本地源码分类模型，不能证明实际模型身份或整体能力。
- HTML 会送达对方服务器。对方 API 任务不自动发布到访客区，任务 ID 不对本站前端公开；任务最长运行 10 分钟，对方结果保留 1 小时。本站保存的终态不受其任务过期影响。

回滚旧二进制可保留新增评估表，不影响原鹈鹕计划、记录和费用数据。

鹈鹕测试有两种：给用户看的**分组测试**（后台侧栏 → 鹈鹕测智），和管理员排查单个账号用的**账号级测试**（账号管理 → 账号操作菜单 → 鹈鹕测智 → 定时测试）。只有分组测试的作品会出现在用户的「鹈鹕测智」展示页。

## 分组测试（用户展示页的数据来源）

后台侧栏 → 鹈鹕测智。页面分三块：用户展示设置、分组测试列表、测试记录。

`/admin/pelican-tests` 的分组名后显示今日和总计测试消耗, 下方每条记录显示测试消耗 (USD).

- 成本口径: 按上游实际返回的 token 用量, 使用实际作答模型的美元定价及账号成本倍率 (`cost_multiplier`) 折算. 输入、输出、缓存读写、Gemini 思考 token 和上游服务档位使用统一计价规则; 不应用用户或分组售价倍率, 不扣用户余额. 账号成本倍率读取 `extra.cost_multiplier`，未配置时沿用参考仓库的 0.1 默认估算；准确性取决于管理员配置, 这不是上游账单对账.
- 换号前的调用和失败作答有用量时也计入该条记录. 不重复累加流式累计用量. 上游未返回用量或模型没有定价时显示未记录; 部分调用未能完整计价时显示部分, 汇总仅累加已知成本. 没选到账号、分组停用等未发起调用的情况记为 0.
- 今日按服务器时区的测试完成日期统计. 同组多个测试计划共用分组汇总. 结果与每日成本在同一条数据库语句中原子保存, 历史按天数或条数清理、删除或重建测试计划均不减少该分组累计成本.
- 迁移 `244_custom_pelican_tests.sql` 为结果增加可空成本快照, 并建立独立的分组每日累计表. 旧记录没有用量数据, 保持未记录, 不补造历史费用. 汇总从升级后开始累计; 回滚到旧版本期间的测试不会自动补记.

测试记录使用与其他表格相同的分页组件, 支持页码、跳页和全站共享的每页条数. 列表每次只请求和渲染当前页, 每 15 秒原位刷新, 不再通过轮询或加载更多累积历史行. 删除测试或自动清理使当前页越界时, 自动返回最后一个有效页. 分组记录接口使用 `page` / `page_size` 参数, 返回 `items`、`total`、`page`、`page_size` 和 `pages`; `plan_id` 仍可筛选单个测试. 该接口不再使用 `before_id` / `next_cursor`.

用户 `/pelican-showcase` 展示卡片在各屏幕断点的宽度缩小为原来的 70%, 预览保持 4:3 比例, 点击后仍可打开大图.

下游携带本站用户 API Key，通过只读 `GET /api/v1/public/pelican-showcase` 获取同一保留窗口的作品摘要，再通过各条 `content_url` 按需读取原始结果。清单和正文均需鉴权，采用 60 秒服务端共享快照、ETag/304、gzip 和有界正文缓存，不触发额外测试；HTTP 缓存为私有且必须重新验证。展示开关同时控制该接口，仅提供已发布的成功作品；详见 [结果开放 API 与接入说明](./pelican-showcase-api.md)。

- **按分组出题**：每个测试绑定一个分组，填写模型（用户请求该分组时用的模型名）、题目（默认鹈鹕骑自行车）、思考强度、每次并行份数（1–8）和频率（预设或标准 5 字段 Cron）。建好后分组不能更换，要测别的分组就新建一个。
- **账号由调度器决定**：每一份都像一个真实请求一样，经 sub2api 的调度器从该分组里挑账号——OpenAI 兼容平台（OpenAI、Grok、Kimi、智谱、DeepSeek、MiniMax、OpenCode Go）走 `/v1/responses` 用的调度器，其余平台走 `/v1/messages` 用的调度器，组合分组先按模型解析目标平台。作答期间占用该账号的一个并发槽，槽满时像排队请求一样等待，最多 1 分钟。
- **换号规则同真实请求**：账号在出内容前就报错（上游 429/5xx、连接失败、令牌缺失等）时，排除它再选一个，最多试 3 个账号；模型已经回复但没画出 HTML、回复为空或超过大小限制时不换号，这就是该分组的真实回答。
- **记录**：每份结果记录作答账号和先试过的账号及其错误，只在管理员页面显示。每个测试保留最近 100 条，超过 7 天自动清理。可以随时「立即运行」一次，不影响原定的下次运行时间；同一个测试正在运行时不会重复开始。
- **发布到展示页**：成功画出 HTML/SVG 的作品复制到该分组的展示页，按「每组最多保留 N 张、可选超过 N 天清理」的规则保留。展示开关关闭时照常测试、收录，只是用户看不到。
- **展示哪些分组**：建了分组测试的分组（暂停的也算）才出现在展示页，按分组排序显示；删除测试后，该分组一分钟内从展示页移除，作品一并清理。

本 custom 使用新增迁移 `244_custom_pelican_tests.sql`，建立分组计划、结果、作品快照与每日费用汇总，并扩展原账号定时测试表。原迁移文件及校验和保持不变。分组结果与账号结果共用序列，保证展示来源 ID 不冲突。回滚前应暂停账号级鹈鹕计划；新表和原用户数据无需删除。

## 账号级测试

账号管理 → 账号操作菜单 → 鹈鹕测智 → 定时测试。结果只进管理员的测试记录，不再发布到用户展示页。

使用专用 `PelicanScheduledTestsPanel`，复用现有计划 CRUD 接口、数据库和后台调度器，支持添加多个计划、编辑、启停、删除和查看结果。每个计划使用标准 5 字段 Cron（默认 `*/30 * * * *`），沿用模型、最大结果数、启用和自动恢复选项；鹈鹕计划另保存题目、思考强度和并行数。关闭网页后仍由服务端执行，不设默认自动停止时间。

- 最大结果数默认 100，可设 1–200，按每份输出计数；每轮 1–8 份并行输出。
- 每次生成后按最大结果数裁剪历史，超过 7 天的记录每分钟清理（每批最多 1000 条），暂停后仍清理。单份文本最多 2 MiB，超限保留失败信息、不保存正文；SSE 捕获最多 4 MiB。数据库删除由 PostgreSQL 常规 autovacuum 回收复用空间，并不保证数据文件立即缩小。
- 每份结果显示生成时间、手动/定时来源、当时的模型与思考强度、耗时。手动测试按各并行请求记录耗时并保存至本地历史，定时测试使用服务端记录；旧手动记录没有耗时时显示“—”，不补造数据。列表只读取摘要，点击后加载 HTML，继续使用隔离 iframe 和 CSP，可下载，不自动评分。
- 自动恢复沿用原选项：启用后，一轮中有成功输出时调用现有账号状态恢复流程；默认关闭。
- 多个鹈鹕计划使用账号级数据库锁和计划租约，防止同一账号的计划同时开始；每轮最多执行 10 分钟，进程崩溃后的租约 15 分钟过期。错过的轮次不批量补跑，暂停后已经开始的一轮会完成。
- 原连接与答案质量测试保留现有组件和行为，鹈鹕入口只列出该账号的鹈鹕计划。手动测试的本地历史保持原入口。

数据库迁移 `244_custom_pelican_tests.sql` 仅为现有计划增加可空配置和租约，为结果增加配置快照；原连接测试的配置为 NULL。运行新功能后回滚到旧调度器前，应先暂停鹈鹕计划。

自动验证使用模拟上游与临时 PostgreSQL/Redis 容器，不调用真实模型。部署后验证健康状态、鉴权、数据库迁移及禁用计划的保存，不启动付费绘图。

## 测试记录展示

测试记录通过管理员专用 `/admin/pelican-test-results` 接口读取全部保留结果摘要，不受账号列表分页/筛选影响。每次输出一张卡片，同账号的多次测试和失败结果都保留；服务端游标分页读取，HTML 正文仅为当前显示的卡片按需加载。每批显示 24 张，更多记录可继续加载，每 15 秒刷新。手动记录从当前浏览器全部鹈鹕历史键读取，以记录/输出 ID 去重，不按账号合并成最新一条。
