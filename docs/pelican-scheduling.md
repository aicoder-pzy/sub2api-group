# 鹈鹕定时测试与最快故障切换

分组和账号的鹈鹕定时测试均支持「按每日时段运行」。时间使用北京时间（UTC+8），开始时间包含、结束时间不包含；06:00–01:00 表示每天早上 06:00 到次日 01:00。关闭时段限制则全天按原有 Cron 频率运行。时段内必须存在 Cron 执行时间，否则保存时会拒绝该配置。手动测试和「立即运行」不受时段限制；时段结束前已开始的测试继续完成。

开启「最快故障切换」或「质量优选」的分组将鹈鹕检测结论用于选号。使用同组、同账号、同模型最近 24 小时内的结论，来源包括账号手动测试、账号定时测试和分组定时测试的实际作答账号。账号级测试的结论在所属分组生效；分组测试只在该组生效。糖果题及其他答案评估不参与降智复测流程。

常规分组测智跟随该分组、该模型当前的正常可用主账号，并行多份也使用主账号，不轮测最久未测的备用账号。主账号故障或资格失效时仍使用原有调度故障切换；账号级手动与定时测试继续固定所选账号。

首次降智进入待复测状态，原账号继续响应请求，五分钟后通过原分组的调度资格检查，固定在原账号执行一条测智请求。复测正常立即取消降智处理；仍降智才确认、选择替代账号、确认新主绑定并立即测试新账号。新账号首次降智同样等待五分钟复测。一个开始于冷却结束之前的并行样本，即便结束较晚也不算复测。失败或无法判定不确认降智，在预算内五分钟后再尝试；已有确认结论须有正常结果才能恢复。确认流程及次数持久化，服务重启不会丢失。

系统设置 → 最快故障切换 →「每小时降智追加测智上限」默认 10，允许 1–100。限额按每个分组、每个上游模型的滚动一小时独立计算，原账号复测及切换后的立即测试各算一次尝试，失败尝试也计入；常规定时及手动测试不计入。达到上限后保留待办、暂停追加测智，预算释放后恢复。已确认降智仍影响下一条请求的选号。自动追加测智必须有启用、模型匹配的鹈鹕分组计划，并遵守该计划的北京时间运行时段；每分钟扫描到期任务，不早于五分钟复测，不改变原 Cron。复用计划题目、检测方式、思考强度，单次追加任务只生成一条。

已确认降智账号排在其他可用账号后面，其当前绑定也不能跳过检测。全部可用候选都已确认降智时按速度选择；最快的已是当前账号时结束轮转，避免反复切换。仍遵守停用、额度、限流、倍率、模型支持和并发约束。已输出的请求继续完成，下一条请求使用新主账号。健康主账号不会因为排名或其他账号恢复而被主动替换，账号切换通知保留并说明复测确认原因。

流量统计查询缓存最多约 30 秒，降智确认状态每次选择读取，保存复测结果后的下一条请求立即生效。管理员可在账号管理的「调度状态」查看原始结论及「首次降智，等待复测确认」「复测仍降智，已确认」和追加测试时间。原始作品判定及智力探测正常率保持按每条真实结论统计，不把待复测样本伪装成正常。只保存评估服务给出的结构化结论；模型生成的 HTML 标签不能改变选号结果。升级将最近的既有降智结论初始化为待复测，并给予五分钟机会。

现有测试计划默认不限制时段；升级不会启用新测试、修改题目或降低模型与思考强度。
