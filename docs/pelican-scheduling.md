# 鹈鹕定时测试与最快故障切换

分组和账号的鹈鹕定时测试均支持「按每日时段运行」。时间使用北京时间（UTC+8），开始时间包含、结束时间不包含；06:00–01:00 表示每天早上 06:00 到次日 01:00。关闭时段限制则全天按原有 Cron 频率运行。时段内必须存在 Cron 执行时间，否则保存时会拒绝该配置。手动测试和「立即运行」不受时段限制；时段结束前已开始的测试继续完成。

仅开启「最快故障切换」的分组将鹈鹕检测结论用于选号。使用同一账号、同一模型最近 24 小时内的最新结论，来源包括账号手动测试、账号定时测试和分组定时测试的实际作答账号。最新正常结果恢复账号；无样本、过期和无法判定结果允许使用。糖果题及其他答案评估不参与这项规则。

疑似降智账号排在其他可用账号后面，其当前绑定也不能跳过检测。A 疑似降智时改选 B；B 也疑似降智时改选 C；全部可用候选都疑似降智时按速度选择，仍遵守停用、额度、冷却、模型支持和并发约束。速度沿用该分组/模型的真实流量延迟统计，没有流量时采用最新检测的生成耗时。正常当前账号沿用原有绑定策略；新账号完整请求成功后才更新绑定。

调度样本查询缓存最多约 30 秒。管理员可在账号管理的「调度状态」查看检测结论、时间和原因。只保存评估服务给出的结构化结论；模型生成的 HTML 标签不能改变选号结果。升级会迁移旧结果中由本服务插入的评估标记。

现有测试计划默认不限制时段；升级不会启用新测试、修改题目或降低模型与思考强度。
