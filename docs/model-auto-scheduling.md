# 模型自动优选

分组编辑页选择「模型自动优选」，然后把三个账号加入该分组。这个模式按分组、模型独立保存主账号、试用会话与评估记录；质量优选和最快故障切换继续保留健康主账号。也支持可用账号数量暂时不足三个的情况，不自动添加或启用账号。

资格检查始终在排序之前：模型规则、额度、冷却、平台、利润保护和实际倍率上限继续生效，倍率等于上限允许使用。当前账号资格失效或发生故障时，沿用现有请求重试、超时和成功后提交主绑定的规则。

## 新会话与试用

已有健康会话继续使用原账号。每十个新会话，九个交给主账号，一个交给备用账号；健康备用账号按账号编号轮流试用。试用使用真实请求，不复制客户请求，不额外调用模型。只有一个健康账号时全部使用它。无样本的账号可以试用，但界面仍显示待验证，不把它认定为质量正常。

会话按分组和模型隔离，Redis 原子分配并保存一小时，后续请求刷新有效期。并发请求只分配一次。试用成功和正常旧会话完成不会改写主账号、不会产生主账号切换通知。暂停、超出倍率、确认降智等账号不能凭会话绑定绕过资格检查。

## 排名与升级

排名先考虑智测和稳定性，然后比较速度与单位成本。手工优先设置不会覆盖自动证据；没有足够证据时使用优先级数字和账号编号稳定兜底。

质量结论沿用同组、同账号、同模型证据，强度保留可见；medium 测智不被称作 xhigh 能力验证。正常和降智历史保留七天，最新结论有效期 24 小时。真实流量按一小时、24 小时、七天统计，24 小时为主要依据，一小时用于近期故障保护。

自动升级速度样本只包含 24 小时内完整成功的流式请求，按相同思考强度比较，再分成输入上下文小于 8K、8K–32K、32K–128K、至少 128K 四档。当前账号与候选的公共输入档，每档各至少五条，公共档累计各至少二十条，使用相同档权重比较 P50/P95，避免流量结构造成误判。测试作品耗时不作为自动升级首字证据。输出速度只使用至少 100 输出 Token 的请求。单位成本使用实际账号费用除以标准费用，历史倍率取调用时快照。

候选必须有近期正常智测结论、请求稳定性不比主账号差，而且至少满足一种明显优势：

- 主账号质量未知或过期，候选连续正常至少两次。
- 成功率的 Wilson 95% 区间支持明显优势，候选下界比主账号上界至少高两个百分点。
- 首字 P95 至少降低 20% 且至少降低一秒，P50 不恶化超过 10%。
- 首字 P50/P95 不恶化超过 5%，输出速度至少快 20%。
- 首字 P50/P95 不恶化超过 5%，输出速度基本相当，单位成本至少低 15%。

每个模型和速度强度独立累计评估票；有请求时最多每五分钟评估一次，同一候选连续三次保持优势，并且距离上次主绑定提交至少三十分钟，才进入可升级状态。优势消失、更换候选、超过十五分钟无评估或主绑定版本改变时重新累计。没有流量时不生成付费探测、不推进评估。缺少历史切换时间的老绑定从首次评估开始计算保持时间。

可升级候选在下一个新会话使用，并且完整成功后才通过现有 Redis 版本比较提交主绑定。失败、取消和旧请求晚完成不能强行覆盖新绑定。管理员收到「模型自动优选升级」通知；必要故障切换仍使用原通知。

## 降智与测试

普通分组鹈鹕测试及并行样本仍跟随当前模型主账号，不试用备用账号、不推进优选评估。没有近期正常结论的备用账号需要单独进行账号测智，结果可作为该账号该模型的证据，不自动增加付费计划或更改检测强度。

首次降智继续服务，暂停正常优选升级；五分钟后固定原账号复测，正常取消处理，仍降智才切换并立即测新主账号。追加检测沿用现有时段与每小时次数限制。全部合格账号确认降智时使用最快的继续服务，避免无限轮换。已输出的请求遵循现有完成和失败处理，不拼接其他账号答案。

## 查看

账号页的分组「调度状态」提供思考强度选择、当前主账号、候选排名、成功率、智测结论、输入档样本、输出速度、单位成本、候选未达到升级要求的原因，以及连续评估和保持时间。GET 只读，不修改评估票、会话分配或主绑定，不发送测试。统计缓存最多三十秒，新智测结论仍按现有样本版本立即失效缓存。
