# 在线聊天

登录后从侧边栏「在线聊天」进入，地址 `/chat`。普通用户和管理员都可使用；管理员也可以在「我的账户」中进入。

1. 选择自己的分组 / API 密钥。没有可用密钥时，到「API 密钥」创建并绑定分组。
2. 选择或输入该分组支持的文本模型，按需调整思考强度，输入消息并发送。
3. 支持流式回答、连续追问、停止生成、重新生成、Markdown 与代码块、复制回答，以及创建、切换和删除会话。

Enter 发送，Shift + Enter 换行；中文输入法组词时按 Enter 不会误发送。模型列表按当前密钥的真实网关结果读取，加载失败时可手动输入模型名，最终权限由网关校验。

聊天沿用当前分组计费、余额/订阅限制、速率限制、模型权限、账号调度和故障切换。每次发送或重新生成均为正常计费请求；前端不会自动重复发送失败请求。使用记录可查看实际费用。第一版每次回答最多 4096 个输出 tokens（包含模型可能使用的推理 tokens），截断会明确标记；可继续追问。

会话按登录用户分别保存在当前浏览器的 localStorage，不跨设备同步。刷新和重新打开会恢复已保存的对话；清理站点数据会删除它们。存储空间不足时会提示保存失败，不删除旧历史。会话只保存文本、模型选项和密钥 ID，不保存 API Key。生成中离开页面或停止时保留已收到的内容；异常关闭浏览器仍可能丢失尚未保存的最新片段。

本功能复用已有 `/v1/models` 和 `/v1/chat/completions` 网关，支持现有文本模型的 OpenAI 兼容入口。Claude Code 专用分组或不接受此协议/思考强度的上游仍会返回原有权限或参数错误，页面不会绕过限制。第一版提供文本对话，附件、工具执行、语音和跨设备同步不在本次范围。

前端只读取当前用户拥有的有效密钥，每次生成前重新检查所有权、分组、到期和额度，再经网关执行最终校验。网关请求不携带面板 JWT，不在本地历史或页面中显示密钥；响应 Markdown 经清理后渲染，禁用内嵌图片等远端资源标签。SSE 解析复用分组缓存测试已有实现，覆盖分块 UTF-8、CRLF、多行数据、取消及不完整终态。
