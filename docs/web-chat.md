# 在线聊天

登录后从侧边栏「在线聊天」进入，地址 `/chat`。普通用户和管理员都可使用；管理员也可以在「我的账户」中进入。

1. 选择自己的分组 / API 密钥。没有可用密钥时，到「API 密钥」创建并绑定分组。
2. 默认打开财务工作台；从“对账与流水核对、预算与经营差异、报表与指标分析、月度经营报告”选择任务，补充期间、币种、单位和核对口径。模板只填写草稿，不会自动发送收费请求。仍可直接普通聊天，在“模型与回答设置”中关闭财务核对模式。
3. 可从 Excel 直接复制单元格粘贴到输入框，或添加、拖入 `.xlsx`、`.xls`、`.csv`、`.tsv`、`.txt`、`.md` 文件。先检查预览，再说明任务并发送。支持多轮追问、停止生成、重新生成、Markdown、复制回答，以及创建、搜索、重命名和删除会话。
4. 回答中的表格可下载为真正的 `.xlsx`，每个表格占一个工作表；“复制首个表格到 Excel”适合直接粘贴。报告下载为独立 HTML 文件，用浏览器打开即可打印或另存为 PDF，不需要安装插件。可导出完整对话为 Markdown。
5. 电脑可直接粘贴截图、拖入图片，或从“添加文件 / 图片”选择 PNG、JPG、WebP；手机网页可选“拍照”调用后置相机，或用“图片 / 相册”选择已有照片。设备不提供相机时由系统提供文件选择器。发送前可放大检查和移除图片；只附图片也可发送。拍照的系统界面由手机浏览器负责，不能保证所有设备一致。HEIC / HEIF 请转为 JPG 或截图上传。

Enter 发送，Shift + Enter 换行；中文输入法组词时按 Enter 不会误发送。模型列表按当前密钥的真实网关结果读取，加载失败时可手动输入模型名，最终权限由网关校验。

聊天沿用当前分组计费、余额/订阅限制、速率限制、模型权限、账号调度和故障切换。每次发送或重新生成均为正常计费请求；文件读取、模板选择和导出不触发模型调用，前端不会自动重复发送失败请求。使用记录可查看实际费用。新对话默认最多 8192 个输出 tokens，可在设置中选 4096 / 8192 / 16384（包含模型可能使用的推理 tokens）；旧对话保留原 4096 限制。截断会明确标记；可继续追问。

会话、草稿、导入资料和处理后的照片按登录账号保存到服务器，并缓存到本机 IndexedDB。电脑与手机登录同一账号，在电脑打开会话并点击“手机接续”，手机扫码即可进入同一段会话。手机点“拍照”，等状态显示“已同步”后，电脑通常在 5 秒内出现待发送照片；电脑可继续输入问题并发送。照片同步、查看和预览不调用模型；点击发送才按所选分组正常计费。也可以在两端的历史会话列表中选择相同会话，无需扫码。

网页可见时每 5 秒检查版本，回到页面或网络恢复时立即检查；未变更时只取版本列表，不重复下载照片。生成回答、解析文件期间暂停当前页面的同步，完成后再同步完整结果；其他设备不会实时显示逐字生成过程。草稿在本机约 400 ms 后保存，停止编辑约 1.2 秒后上传；关闭页面前请确认“已同步”。网络中断时保留本机内容，恢复后继续同步。两端分别修改文字和添加照片可合并；同一内容同时改成不同版本时保留为“冲突副本”，不直接覆盖其中一份。删除采用版本校验，其他设备的旧缓存不能恢复已删会话；尚未同步的新编辑会保留为副本。

旧浏览器历史首次使用自动导入，兼容原 localStorage；成功缓存到 IndexedDB 后移除旧副本。本机缓存读取失败时暂停保存和发送以保护原记录，云端同步失败单独显示状态。清理站点缓存不会删除已同步的云端记录，未同步内容仍可能丢失。服务器接口只允许当前账号访问，二维码和链接不含登录凭证，其他账号无法读取；不保存 API Key 或原始照片。处理后的图片、提取的表格内容会保存在服务器会话中，导出 Markdown 也包含已发送图片。每个会话最多 24 MiB / 500 条消息，每账号最多 100 个有效会话 / 200 MiB，超出后提示导出并删除旧会话；不自动裁剪资料或删除历史。

图片原图最多 20 MB / 4000 万像素，在浏览器解码并按相机方向绘制到 canvas，最长边缩至 2560 像素；PNG 优先保留无损，否则输出高质量 JPEG，去除 EXIF/GPS 等拍摄元数据。处理后单图数据最多 2 MiB（base64，约 1.5 MiB 二进制），图片和文件合计最多 4 个/次；整个请求最多 12 张图、16 MiB base64 图片数据（约 12 MiB 二进制）。超限或任一附件失败时拒绝整个选中批次，不降清晰度重试、不丢弃资料。建议裁剪票据或表格区域，发送前检查预览是否可读。

图片以标准 Chat Completions `image_url` 数据部分发送，网关沿用现有直接转发或 Responses 转换能力，后续追问保留图片。需所选模型和渠道本身支持看图；模型列表没有可靠视觉能力字段，因此不会根据名称承诺支持，也不会自动改模型或把图片变成普通文本。上游拒绝时提示检查模型、渠道和参数。读取、预览、恢复、导出不会调用模型；点击发送、重新生成及后续含图追问按模型规则计费。无需另接 OCR 服务，也不会自动发起一次识别收费请求。

文件在隔离的浏览器 Worker 中解析，10 秒超时会终止 Worker，避免大文件阻塞页面。每个文件最多 5 MB，每次最多 4 个；每张工作表范围最多 2000 行、60 列，所有工作表合计最多 30000 个单元格，每个文件最多 12 张工作表。仅导入可见工作表，保留源文件行号和 Excel 已保存的显示格式；CSV/TSV 不做数字自动转换，兼容 UTF-8 与 GB18030 文本。单文件提取内容最多 10 万字符，单次资料及问题最多 12 万字符，累计对话超过 30 万字符会在请求发出前拒绝。范围过大、公式错误、缺少计算缓存或无法读取时拒绝整个选中文件批次，不悄悄截取前几行。

解析不会执行公式、宏或外部链接。公式使用源文件保存的结果并附原公式供检查，缓存可能过时，业务核对前应先在原表重新计算保存。原文件已丢失的长数字精度无法恢复。发送时，提取后的内容作为用户数据提交给当前模型，后续追问继续携带这些资料，正常计费；本机历史也保存该文本。界面明确提示资料流向。Excel 导出全部按文本单元格保存，避免模型内容成为公式并保留单号、前导零；粘贴导出对公式起始字符、长数字和前导零进行文本保护。需要计算时先核对并转换相应金额列格式。

财务核对模式要求明确期间、单位、匹配字段和容差，区分精确/疑似匹配，引用文件、工作表和行号，区分事实与估算，不编造缺失数据。对图片先列出识别字段和原文，引用图片名；模糊、缺失或遮挡字符标为待确认，要求用户核对金额、日期、单号后再据此对账。识别由当前视觉模型完成，不能视为已验证的财务数据。助手没有本地代码执行、电子表格计算或源文件编辑工具，不能替代确定性批量核算；大规模金额计算提供 Excel 公式和复核步骤，界面提示复核金额与结论。导出的是回答中的表格和文字，不是修改过的源工作簿。PDF、Word 读取及独立 OCR 服务不在当前支持范围。

本功能复用已有 `/v1/models` 和 `/v1/chat/completions` 网关，支持现有文本模型的 OpenAI 兼容入口。Claude Code 专用分组或不接受此协议/思考强度的上游仍会返回原有权限或参数错误，页面不会绕过限制。没有新增服务端上传目录、数据库表、软件安装或依赖包；工具执行、语音和跨设备同步不在本次范围。

前端只读取当前用户拥有的有效密钥，每次生成前重新检查所有权、分组、到期和额度，再经网关执行最终校验。网关请求不携带面板 JWT，不在本地历史或页面中显示密钥；响应 Markdown 经清理后渲染，禁用内嵌图片等远端资源标签。SSE 解析复用分组缓存测试已有实现，覆盖分块 UTF-8、CRLF、多行数据、取消及不完整终态。
