# 定时答案质量检测

参考 [ranxi2001/sub2api 降智运维](https://github.com/ranxi2001/sub2api/blob/main/docs/account-quality-operations.md)，在 custom 已有账号定时测试中增加语义判题。

在「账号管理 → 账号操作 → 定时测试」添加或编辑计划：

1. 选择 OpenAI 文本测试模型，配置五段 Cron。
2. 填写测试题、预期答案和推理强度。推理强度留空时使用上游默认值。
3. 选择 OpenAI 判题分组和判题模型，按需填写判题说明。判题分组必须有另一个支持该模型的可调度账号。
4. 展开计划查看历史、原始回答和判题理由。

填写预期答案即启用质量检测；清空预期答案可关闭。当前每次计划执行测试一次。测试与判题均为真实模型请求，会消耗对应账号额度。

判题比较参考答案与被测回答的语义，允许措辞和格式差异。被测账号及共享同一母账号凭据的影子账号不能给自己判题。测试和判题占用账号并发槽，判题遵守分组模型白名单、账号模型支持和全局模型账号限制；判题请求或输出解析失败时最多尝试三个账号。

结果分为「答案正确」「可能存在降智」「无法判断」。只有判题器明确返回 `incorrect` 才记录错答；网络错误、超时、空回答、未完成响应、没有判题账号和无效判题 JSON 均为无法判断。记录保留错误和回答文本。一次错答只代表该题目和配置下的表现，不能证明模型整体能力下降。

此版本提供定时检测与历史，不包含参考仓库的每轮 1–8 次采样、独立质量运维页、自动移出分组、关闭调度、BPS 自动切换或隔离恢复。现有「自动恢复」只在测试成功且答案正确时清理原有可恢复运行错误，不重新绑定分组或开启调度。普通连通性计划按原方式执行。

迁移 `243_add_scheduled_test_quality_check.sql` 仅新增字段，已有计划仍为连通性测试。后台执行器按进程防止扫描重叠；多副本部署尚无数据库执行租约，需仅在一个实例启动该执行器。
