# 渠道统计

后台入口：`/admin/channel-statistics`。管理员可以查看今天、昨天或最近最多 7 个北京时间自然日，按分组、请求模型、实际思考强度筛选；默认模型 `gpt-6.1-sol`。今日数据截至查询时刻。查询跨度和最早日期都受后端约束，不改变原始用量日志的保存期限。

页面包含汇总卡片、按账号比较、按日统计、每日上游消耗和 CSV 导出。首字延迟显示平均、P50、P95、超过 30/60 秒次数和有效样本数。非流式和缺失首字时间的调用不计入首字延迟，缺失显示 `—`。输出速度是输出 Token /（总耗时 − 首字时间）的估算中位数。上下文中位数帮助识别负载差异。

上游成功率 = 未发生该账号上游失败的完成调用 /（该类成功 + 失败请求）。失败按同一请求和账号去重，包含最终恢复的重试失败；客户端错误、无账号路由失败及明确属于请求/供应商/代理范围的事件不归因到账号。指定思考强度时，仅通过同一请求的用量记录确认强度；无法确认的失败单列，避免把全部强度的失败除以某一强度的调用。错误日志被清理或未记录时可能低估失败。

智力探测使用所选日期内的结构化鹈鹕样本。正常率 = 正常 /（正常 + 疑似降智），有效样本超过 10 次才显示；未知、失败单列。指定分组只统计该组样本，全部分组还包含账号级单测。此页按日期统计，与分组监控的最近 100 条有效样本窗口不同；不修改调度规则、账号优选或测试计划，不主动发送模型调用。

消耗单位 USD：

- 上游成本：`SUM(COALESCE(account_stats_cost, total_cost) * COALESCE(account_rate_multiplier, 1))`。
- 用户扣费：`SUM(actual_cost)`。
- 标准消耗：`SUM(total_cost)`。

这些金额使用每条历史记录的价格、倍率和扣费快照。未记入本站的上游失败额外收费不在其中。CSV 使用原始毫秒、Token 和数值金额，同时携带日期、时区、筛选条件与生成时间。

## 管理员 API

`GET /api/v1/admin/usage/channel-statistics`

需要已有管理员 Bearer 登录令牌。返回标准 `{code, message, data}` 包装。用户令牌不能访问。

| 参数 | 说明 |
| --- | --- |
| `start_date` | `YYYY-MM-DD`，默认北京时间今天 |
| `end_date` | 包含该日期，默认等于开始日期 |
| `group_id` | 正整数；省略或 0 表示全部 |
| `model` | 请求模型，省略表示全部 |
| `effort` | 实际思考强度，省略表示全部；支持 none/minimal/low/medium/high/xhigh/max/ultra |

例如：`?start_date=2026-10-07&end_date=2026-10-13&group_id=24&model=gpt-6.1-sol&effort=xhigh`。日期必须在查询时刻最近 7 个自然日内，不接受未来日期或倒序范围。

`data` 包含 `start_date`、`end_date`、`timezone`、`generated_at`、`summary`、`accounts`、`daily`、`models`。三个统计区复用同一数据库快照；每日无数据补零，延迟保留 null。账号仅有失败或测智也会出现，已删除账号保留标识。模型选项来自该日期/分组的数据。百分比由成功/失败、正常/降智计数计算，不能将未知计作正常。
